# 📌 About The Project

Managing personal finances often becomes difficult when income, expenses and budgets are scattered across different places.

**FinTrack** solves this problem by providing a centralized personal finance management platform where users can:

- Manage their financial transactions
- Track income and expenses
- Create and manage budgets
- Search, filter and sort transactions
- Analyze financial activity
- Securely manage their account
- Access their data through a responsive dashboard

The application follows a **full-stack client-server architecture** with authentication and user-specific data isolation.
